# GPay C++ Simulation

A beginner-level C++ console project that simulates basic digital payment
functionality using Object-Oriented Programming.

## Features

- Create multiple user accounts
- UPI ID based account search
- PIN authentication
- View account details
- Check available balance
- Send money between accounts
- Insufficient balance checking
- Testing mode for viewing all accounts

## Concepts Used

- Classes and Objects
- Constructors and Destructors
- Encapsulation
- Arrays of Objects
- Functions
- Function Parameters
- `this` Pointer
- Loops and Conditional Statements
- Basic Authentication Logic
